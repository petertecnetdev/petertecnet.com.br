# Peter Tecnet — Agent Decisions

Registro de decisões duradouras da coordenação multiagente.

## DEC-001 — GitHub como memória compartilhada
**Status:** ACCEPTED  
**Data:** 2026-09-18  
O repositório central `petertecnetdev/petertecnet.com.br` é a fonte compartilhada de comunicação e continuidade entre contas externas.

## DEC-002 — Agente ≠ plataforma
**Status:** ACCEPTED  
**Data:** 2026-09-18  
NP01/NP02/etc. identificam contas/agentes. Cutinapp, API, Nexus, Plat, Rasoio, Locaio, Kryvion, Payflow, Laora, Peter Tecnet e Admin Center são contextos de trabalho.

## DEC-003 — Continuidade por checkpoint
**Status:** ACCEPTED  
**Data:** 2026-09-18  
Não usar cadeia artificial de tarefas para burlar limites da plataforma. Toda execução termina com checkpoint e a próxima execução autorizada retoma daquele ponto.

## DEC-004 — Evidência para conclusão
**Status:** ACCEPTED  
**Data:** 2026-09-18  
Tarefas técnicas só alcançam DONE com evidência verificável quando aplicável.
