# Claims

Claims impedem duas ou mais tarefas de trabalharem inadvertidamente no mesmo escopo.

## Diretórios
- `active/`: trabalho em andamento.
- `completed/`: histórico encerrado.

## Nome
`YYYYMMDD-HHMM-<agent-id>-<slug>.md`

Cada claim deve ser um arquivo independente.

Não sobrescreva claim de outro agente. Para cooperar, envie um handoff em `../messages/`.
