# Messages and Handoffs

Canal assíncrono entre agentes.

Cada mensagem deve ser um arquivo independente:
`YYYYMMDD-HHMM-<from>-to-<to>-<slug>.md`

Use mensagens para:
- pedir revisão;
- avisar dependência;
- informar regressão;
- solicitar integração;
- transferir responsabilidade;
- registrar decisão que outra frente precisa conhecer.

Não use mensagens para armazenar segredos ou dados sensíveis.
